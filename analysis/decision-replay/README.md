# Повторный выбор пилота после нового наблюдения

**Что показать за минуту.** В первом учебном срезе для набора хватает семей. Во втором уменьшается число семей, которые ещё успевают передать ГБ, и растёт число владельцев, которым ещё можно помочь оплатить свой номер. При одном и том же пороге рекомендация меняется. Прочтите две последние строки расчёта по очереди, затем передайте вопрос о финансировании руководителю. [Результат прогона](result.md)

Из корня репозитория:

```sh
python3 analysis/decision-replay/replay.py
```

**Откуда числа.** Все четыре строки CSV придуманы для демонстрации. Используем учебный пример из протокола №2 — 160 уникальных единиц суммарно на два плеча одного пилота и четыре полные недели набора после подготовки и резерва на наблюдение. Получаем 40 единиц в неделю. Каждый новый срез отдельно отвечает на вопрос, хватит ли набора, **если его темп сохранится**. Реальному пилоту нужны расчёт выборки и несколько недель для проверки устойчивости потока. Параметры команды меняются через `--sample`, `--weeks` и `--input`. [Учебные данные](weekly.synthetic.csv) · [Протокол №2](../audience-kpi/README.md#какой-результат-среза-нужен-руководителю)

**Как читать строку CSV.** Неделя начинается в понедельник в 00:00 МСК. Каждая единица попадает в один сегмент и один раз за весь набор, по первому эпизоду риска. В учебных данных предполагаем полные журналы. Каждая следующая колонка считает часть предыдущей.

| Колонка | Семья с общим пакетом | Владелец своих номеров |
| --- | --- | --- |
| `first_risk` | Уникальные семьи с риском исчерпания доли на совместимом тарифе | Уникальные владельцы с предстоящим списанием по целевому номеру |
| `permitted` | Действует согласие участника, организатор вправе распределять пакет | Подтверждены принадлежность номера и право видеть начисление |
| `actionable` | Есть свободные ГБ, которые можно передать участнику | Сумма и срок известны, риск сохраняется с учётом обычной оплаты и автоплатежа |
| `in_time` | Данные доступны, пока остаётся время на перенос | Данные доступны, пока плательщик ещё успевает подтвердить оплату |

### Как меняется рекомендация

| Новое наблюдение | Предложение руководителю | Существенный контраргумент |
| --- | --- | --- |
| **2–8 ноября.** Успевают 54 семьи и 24 владельца. У владельцев после проверки прав из 90 случаев остаётся 31 с доступным действием, из них 24 своевременны. | Обсудить семейный пилот. Набор превышает порог на 14 семей в неделю. | Перенос может исчерпать пакет другого участника. В пилоте сравнить ограничения по всей семье и до отправки перепроверять согласие. |
| **9–15 ноября.** Успевают 29 семей и 51 владелец. При тех же 80 семьях с правами свободный пакет есть у 44, вовремя действовать могут 29. У владельцев остаются 63 пригодных действия, из них 51 своевременно. | Пересмотреть прежнее предложение и обсудить пилот напоминаний. Владельцы выше порога на 11, семьи ниже на 11. | Часть платежей пройдёт сама после момента отбора. Перед отправкой повторно сверить зачисление, а ограничения из-за неоплаты сравнить с обычным обслуживанием. |

### Где меняются оценки и где агент останавливается

У `family_signal` и `own_reminder` пересматриваем **исполнимость в срок** (`delivery`) и возможность **получить результат эксперимента к концу II квартала** (`learning`). В первом срезе основание для этих оценок усиливается у семей, во втором — у владельцев. Для условия `resources` проверена только составляющая набора. Бюджет, календарь команды и возможность безопасной отправки требуют отдельного подтверждения. Недельные данные относятся к пробелу E9. Для оценки клиентской пользы нужен контроль, для экономики по E6 — дополнительные оплаченные номеро-месяцы и прямые расходы. [Исходная карта оценок](../../demo/family/first-run/scoring.json) · [Основания E2, E6, E7 и E9](../../demo/family/first-run/evidence.md)

После второго среза агент предлагает обсудить напоминание владельцу. Руководитель может выбрать пилот, запросить дополнительную диагностику, сохранить обслуживание или закрыть подготовку сигналов. До его ответа этап дела — `awaiting_choice`, решение — `null`. [Сохранённый вопрос и пять вариантов](../../demo/family/first-run/state.json)
