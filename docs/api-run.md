# Запуск стратегии с ключом OpenAI

Из корня репозитория запустите Python 3.9 или новее. Нужны сеть и API-ключ проекта OpenAI с доступом к модели. По умолчанию используется `gpt-4.1-mini`; другую доступную модель Responses API с JSON-выводом можно указать через `--model`. Программа скрыто запрашивает ключ в терминале либо читает уже заданную переменную `OPENAI_API_KEY`. SDK и подписка на ассистента для редактора не требуются. [Документация Responses API](https://developers.openai.com/api/reference/resources/responses/methods/create)

```sh
python3 tools/run_api.py new work/my-strategy --question "Какую проверку стоит профинансировать?" --file demo/family/Бриф.md --max-calls 4
```

Откройте `work/my-strategy/comparison.md`. В нём есть цитаты с номерами строк, допущения, варианты и возражение к каждому. Проверьте, что цитата действительно подтверждает вывод. В терминале видны номера вариантов. Например, если после чтения вы выбираете вариант 1:

```sh
python3 tools/run_api.py resume work/my-strategy --choose 1 --reason "Сначала подтвердим доступный поток на данных биллинга"
python3 tools/run_api.py resume work/my-strategy
```

После выбора читайте `strategy.md` с продуктовой и коммуникационной стратегиями, измерением результата и ближайшим решением. Последняя команда показывает сохранённый этап. При сетевой ошибке она продолжает незавершённый этап, при готовом результате работает локально. Для нового вопроса или другого решения используйте новую папку.

Каждый `--file` разрешает отправить указанный UTF-8 файл (MD, TXT, CSV или JSON) вместе с вопросом в OpenAI. Можно повторять флаг, суммарный предел 160 000 байт. Без файлов модель работает только с вопросом. Для второго вызова отправляются те же снимки источников, сравнение и решение человека. Снимки и прогресс хранятся локально в `api-state.json`. В новую папку дела записывается собственный `.gitignore`. Ключ передаётся в заголовке авторизации. Не включайте секреты в вопросы и разрешённые файлы.

Для новой папки можно дополнить команду `new` аргументом `--finance demo/workshop/investment/finance-v1.csv`. Штатный сборщик создаст локальную редактируемую `investment-model.xlsx` из указанного финансового CSV. Модель отражает варианты и сценарии именно этого CSV. Для включения его данных в запрос отдельно укажите его через `--file`. Вычисления из неподготовленного брифа автоматически не подставляются.

Обычный путь требует двух вызовов. Каждая попытка, включая сетевую ошибку, занимает одно место. Автоповторов нет. По умолчанию разрешены четыре попытки на дело, максимум восемь, до 4 000 выходных токенов за запрос. Это ограничивает число запросов, стоимость зависит от модели и объёма текста. При 401 проверьте ключ, при 429 — квоту и частоту запросов. Если лимит попыток исчерпан после исправления причины, его можно явно увеличить:

```sh
python3 tools/run_api.py resume work/my-strategy --max-calls 6
python3 -m unittest discover -s tools -p 'test_run_api.py'
```

Тест запускает сервер на 127.0.0.1, проверяет новый вопрос, ручной выбор, возобновление, неверный ключ и превышение лимита. Сервис OpenAI в тесте не вызывается.

### Редактируемая презентация

После выбора рядом с Markdown появляется `strategy.pptx` из шести альбомных слайдов. В ней есть решение и его основание, сравнение вариантов, источники и пробелы, продуктовая и коммуникационная стратегии, измерение эффекта и следующий шаг. Текст и таблица состоят из редактируемых элементов PowerPoint. Длинные фрагменты показаны в сокращении, полный текст по каждой теме находится в заметках докладчика.

Если файл потерян, запустите `python3 tools/run_api.py resume work/my-strategy` в каталоге проекта. Для завершённого дела достаточно Python, сохранённого `api-state.json` и комплектного шаблона. Ключ и сеть для этой команды не нужны. Уже существующий PPTX сохраняет ваши ручные правки. Для повторной сборки рядом со своей редакцией сначала переименуйте её. Подробную инвестиционную защиту собирают отдельно из заполненного версионного дела через `tools/handoff.py`; её входы описаны в [руководстве по глубокой выдаче](../methods/investment-review.md).
