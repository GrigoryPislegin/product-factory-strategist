# Стратег Фабрики продуктов

Откройте папку агента в Codex или Claude Code и опишите решение, которое вам предстоит принять. Для отдельного запуска с ключом OpenAI подойдёт обычный терминал и Python 3.9+; команда приведена ниже. Агент уточнит задачу, соберёт доказательства из разрешённых материалов и покажет варианты с возражениями. После вашего выбора он подготовит согласованные продуктовую и коммуникационную стратегии, план проверки и редактируемую презентацию. Дело можно открыть в новом чате.

## Какой результат нужен

Первый вопрос агента — «Это быстрый разбор для встречи, выбор пилота или защита инвестиций?» Режим сохраняется в деле. Если масштаб изменился, можно продолжить в следующей версии.

| Ситуация | Что исследует агент | Что открыть на примере |
| --- | --- | --- |
| Быстрый разбор. Завтра встреча с руководителем | Берёт имеющиеся источники, выделяет главный пробел, проверяет один порог и фиксирует ближайший шаг | [4 слайда: оглавление, сравнение, деньги, решение](demo/family/first-run/strategy-quick.pptx) |
| Выбор пилота. Две команды претендуют на общий ресурс | Сравнивает аудитории, пользовательские операции, коммуникации, сроки, пользу и вред. Считает экономику | [6 слайдов для решения продуктового комитета](demo/family/first-run/decision-brief.pptx) |
| Инвестиционная защита. Нужно обосновать бюджет и риск | Проверяет поток, поквартальный вклад, чувствительность, неблагоприятный сценарий и условия окупаемости. Прикладывает воспроизводимую модель | [Основная защита и приложения, PDF](demo/family/decision/strategy.pdf) · [Редактируемый Excel](analysis/market-finance/investment-model.xlsx) · [Метод принятия решения](methods/investment-review.md) |

На стартовой странице выберите глубину и скопируйте готовый запрос в свой клиент. Поддерживаются Codex и файловые агенты, способные читать локальную папку. В обычном чате приложите общий навык и разрешённые материалы. Сохранение файлов и запуск вычислений зависят от возможностей чата. Готовые презентации и калькулятор доступны без регистрации. Точное время и расход зависят от задачи; отдельно измерены демонстрационные запуски.

## Как открыть

Скачайте ZIP или клонируйте репозиторий. Распакуйте ZIP целиком. Для командной разработки нужен клон с историей Git.

| С чем вы пришли | Первый шаг |
| --- | --- |
| Хочу посмотреть без регистрации | Дважды нажмите **Старт.html** в распакованной папке. Презентация, сравнение и калькулятор порога доступны офлайн. В интерфейсе GitHub HTML отображается как исходный код. |
| Есть подписка на Codex или Claude Code | Откройте корень папки в клиенте или запустите в нём `codex` либо `claude`. Проверьте, что вошли под своим аккаунтом с доступом к клиенту. |
| Есть локальная модель, подписки нет | Установленные Codex CLI и Ollama запускают агента командой `codex --oss --local-provider ollama -m ИМЯ_ЛОКАЛЬНОЙ_МОДЕЛИ`. Имя берётся из `ollama list`. Нужна модель с вызовом инструментов и подходящим окном контекста. Для Codex документация Ollama рекомендует от 64k. [Инструкция Ollama](https://docs.ollama.com/integrations/codex) |
| Хочу использовать свой API-ключ | Запустите Python-команду ниже. Терминал запросит ключ OpenAI скрытым вводом. [Самостоятельный запуск и возобновление](docs/api-run.md) |
| Есть только обычный чат | Приложите файлы разрешённого дела и текст общего навыка. Возможность читать, сохранять файлы или запускать расчёт зависит от чата. Для полноценного воспроизводимого прогона используйте клиент с локальной папкой и инструментами. |

Для локальных расчётов достаточно Python 3.9+ со стандартной библиотекой. Для поиска внутри текстового PDF нужен `pdftotext` из Poppler или инструменты чтения PDF вашего клиента. Для сканов нужна доступная в среде OCR. Возможности поиска по сайтам зависят от клиента. Командная папка с материалами работает без отдельной БД и серверного приложения.

## Самостоятельный запуск с API-ключом

В распакованной папке выполните команду. Ключ можно ввести в терминале, когда его запросит программа, или заранее задать через `OPENAI_API_KEY`. Платные обращения идут в ваш проект OpenAI.

```sh
python3 tools/run_api.py new work/my-strategy --question "Какую проверку стоит профинансировать?" --file demo/family/Бриф.md --file demo/family/baseline.csv
```

Откройте `work/my-strategy/comparison.md`, прочитайте варианты и выберите номер. Если после чтения вы выбрали первый вариант, продолжите командой ниже и запишите своё основание.

```sh
python3 tools/run_api.py resume work/my-strategy --choose 1 --reason "Сначала проверим поток по данным биллинга"
python3 tools/run_api.py resume work/my-strategy
```

Два обычных вызова дают сравнение вариантов, `strategy.md` с обеими стратегиями и редактируемый `strategy.pptx` на **6 альбомных слайдов**. В заметках слайдов сохраняется полный текст. Готовый `resume` восстанавливает удалённую презентацию локально, без дополнительного обращения к модели. Флаг `--finance` при создании добавляет Excel из подготовленного сценарного CSV. Исходники MD, TXT, CSV и JSON передаются только по явно указанным путям. Самостоятельный режим сохраняет дело в `api-state.json`. Инвестиционная презентация по учебному оператору лежит в демонстрационном проекте. Автотест проверяет запросы на локальном сервере, ручной выбор, возобновление и ошибки 401/429. [Все параметры и лимит попыток](docs/api-run.md)

## Что сказать агенту

Для первого прогона откройте корень проекта и введите:

> Начни новое исследование по исходникам в demo/family. Рассмотри семейное предупреждение о трафике и напоминание об оплате своего номера на равных. Сравни их с обычным обслуживанием и закрытием инициативы. Дойди до выбора руководителя. Сохрани результаты в work/first-run.

Источники лежат в `Бриф.md`, `baseline.csv`, `Источники.md` и на указанной в реестре открытой странице. При наличии оригинала из кабинета можно положить его рядом под именем `Пример брифа.pdf`. Папки `checkpoint/` и `first-run/` — примеры сохранённых состояний. Для нового исследования агент берёт исходные материалы. Для другой отрасли попробуйте [кейс библиотеки](demo/workshop/brief.md) или назовите свою папку.

В Codex навык вызывается как `$product-strategist`, в Claude Code — `/product-strategist`. В файловом клиенте без автоматического обнаружения попросите прочитать [.agents/skills/product-strategist/SKILL.md](.agents/skills/product-strategist/SKILL.md).

**Продолжение.** В новом чате той же папки напишите «Продолжи work/first-run. Какие варианты открыты, от чего зависит выбор и каким будет следующий шаг?» Для переноса между компьютерами скопируйте целое дело с разрешёнными исходниками. При смене решения агент сохраняет предыдущую версию.

## Проверить локально

```sh
python3 tools/check.py gaps demo/family/baseline.csv
python3 tools/find_evidence.py --query "прибыль" --limit 2 demo/family/baseline.csv
python3 tools/check.py state demo/family/first-run/state.json
python3 tools/score.py demo/family/first-run
python3 tools/deck.py demo/family/first-run/presentation.json my-brief.pptx
python3 -m unittest discover -s tools -p 'test_*.py'
```

Команды пересчитывают финансовый разрыв, находят строку с источником, проверяют состояние, показывают оценку пяти вариантов и собирают новый PPTX. Для выпуска следующей версии укажите новое имя файла.

**Расход и инструменты.** В первом прогоне на брифе Codex дошёл до выбора за 83 секунды, CLI сообщил 45 795 токенов. Расчёт скоринга и сборка PPTX выполняются локально.
