# Маршрутизация и стоимость

Сначала реши, что предстоит узнать. Чтение указанной строки, пересчёт диапазонов и экспорт PowerPoint выполняются локально. Модель нужна для интервью, интерпретации и выбора следующего действия. Семантически сложный вопрос можно решить в одной сессии. Вывод отдельной модели оправдан, если цена ошибки или реальный выигрыш это подтверждают.

| Действие | Первый маршрут | Когда изменить маршрут |
| --- | --- | --- |
| Извлечь строку, найти страницу, сверить число | Python, таблица, локальный поиск | Нет совпадения — изменить запрос, проверить заголовки и соседние строки, для скана отметить необходимость OCR |
| Классифицировать короткие выдержки | Экономичная модель, доступная в выбранном клиенте | Потерялся локатор или единица — проверить вручную по первоисточнику |
| Объяснить расхождение или сравнить гипотезы | Основная модель с коротким пакетом оснований, ограничений и альтернатив | Если вывод меняется от допущения, провести независимую проверку или запросить наблюдение |
| Жёсткое условие, финальный выбор, публикация | Правило и человек, с указанием точных оснований | После ответа обновить состояние и привязанные документы |

В конфигурации команды можно использовать Luna для извлечения и Sol для синтеза, при сложном конфликте — доступную Astra. В Claude Code аналогичные роли выполняют доступные Haiku и Sonnet, при необходимости — Opus. Это роли, а не имена, гарантированно доступные в любой подписке. У пользователя может быть одна модель. Укажи фактически запущенную модель из клиента. Смена провайдера или режима оплаты требует выбора пользователя. [Управление моделями Claude Code](https://code.claude.com/docs/en/model-config)

## Как считать

Записывай по сеансу задачу и границу измерения, клиента и модель, время, входные, кэшированные и выходные токены, повторные ходы, внешние расходы на поиск и инструменты, минуты человека и известные списания. Метку «неизвестно» сохраняй для каждого отсутствующего значения. Доля оплаченного периода подписки, лимит и денежное списание — разные показатели. Локальная модель использует время оборудования и электроэнергию.

Команда ниже показывает фактические счётчики завершённых ходов Codex по журналу конкретного запуска. Сырой журнал хранится локально и может содержать исходные материалы. Для командного отчёта достаточно итоговых чисел.

```sh
python3 tools/usage.py --codex-log work/session.jsonl
python3 tools/usage.py --total 45795
```

Для оценки цены на API добавь к команде с журналом `--rates INPUT CACHE OUTPUT`. Это три тарифа на миллион токенов из договора или текущего прайса выбранной модели. Входные Codex включают попадания в кэш. Стоимость модели = ((входные − кэш) × обычный тариф + кэш × тариф кэша + выходные × выходной тариф) / 1 000 000. Для полного бюджета добавь фактическую цену поиска и инструментов и время сотрудника по его ставке. Не переноси схему кэша другого провайдера без нормализации. При единственном известном итоге денежную оценку этот инструмент не вычисляет.

Для сравнения экономии используй один и тот же вопрос, материалы, модель и критерии приёмки. Отдельно сравнивай время, токены, качество проверяемых выводов и пригодность результата к продолжению. Один прогон показывает порядок расхода в этом сценарии. Установи бюджет времени и приоритеты, затем предложи самый короткий набор наблюдений, способный поменять выбор.
